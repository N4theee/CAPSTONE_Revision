# Proxamity branding

- `app-logo.png`: launcher artwork prepared from the supplied logo, with the baked-in checkerboard removed and an opaque square background.
- `logo-source.png`: supplied artwork, re-encoded as a valid PNG.
- Platform icon sizes are generated by `tool/generate_app_icons.ps1` on Windows.
- Dashboard initials use the exact characters 𝓟𝓡𝓧 with the bundled Noto Sans Math font; its license is in `assets/fonts/OFL.txt`.
- The login landing page retains the original proximity symbol. Script lettering is limited to student and teacher dashboards.

Rebuild/install the app to see launcher icon changes. Hot reload only refreshes the in-app interface.
